# Retail Sales Analysis

An interactive retail sales dashboard built with **Microsoft Excel** and
**Power BI** to analyze sales performance, customer segments, product
categories, discounts, and monthly sales trends.

## 📊 Project Overview

This project analyzes retail transaction data to understand overall sales
performance and identify patterns across products, customers, discounts,
and time.

The project follows a two-stage workflow:

- **Microsoft Excel** for data cleaning and validation
- **Power BI** for data analysis, DAX calculations, and interactive
  visualization

The goal is to transform raw retail transaction data into clear business
insights.

## 📁 Dataset

**Retail Sales Dataset**

The dataset was obtained from Kaggle:

[Retail Sales Dataset](https://www.kaggle.com/datasets/noopurbhatt/retail-sales-dataset)

- **Rows:** 120,000
- **Columns:** 17

The dataset contains retail transaction information including sales,
quantity, customers, categories, customer segments, discounts, and dates.

## 🧹 Data Preparation — Excel

Microsoft Excel was used for data cleaning and validation.

The preparation process included:

- Checking for missing values
- Checking for duplicate transactions
- Verifying data types
- Checking categorical values for consistency
- Checking numerical values for invalid entries
- Validating the dataset before analysis

## 🎯 Analysis Questions

The project explores questions such as:

- What is the overall sales performance?
- How do sales change across different months?
- Which product categories generate the highest sales?
- How do sales compare across customer segments?
- How are sales distributed across different discount levels?
- Which areas of the dataset show the strongest sales performance?

## 📊 Analysis & Dashboard — Power BI

Power BI was used for data analysis, DAX calculations, and visualization.

The dashboard includes:

- **Total Sales**
- **Total Quantity**
- **Total Customers**
- **Total Transactions**
- **Average Discount**
- **Monthly Sales**
- **Sales by Category**
- **Sales by Customer Segment**
- **Sales by Discount**

## 📈 Key Insights

- **Beauty** has the highest total sales among the analyzed categories,
  while **Clothing** has the lowest.
- Sales are relatively similar across the four customer segments.
- Monthly sales remain relatively stable throughout the year, with some
  month-to-month variation.
- **0% discount** records the highest total sales in the analyzed dataset.
- The dashboard shows that sales performance can be examined from multiple
  perspectives, including product category, customer segment, discount,
  and time.
